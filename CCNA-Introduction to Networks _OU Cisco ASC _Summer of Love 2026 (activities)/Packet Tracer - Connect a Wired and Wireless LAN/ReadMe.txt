Assessment Overview

This activity involved exploring and configuring a simulated network environment, focusing on basic networking tools, device identification, and establishing physical and logical connections.

Parts Completed

Part 1: Connect to the Cloud
Explored the network interface to establish connections linking the local infrastructure to the external cloud network using the correct cabling.

Part 2: Connect Router0
Identified the appropriate interfaces and ports to successfully connect Router0 to the designated network segments.

Part 3: Connect Remaining Devices
Practiced connecting the rest of the end devices and intermediate network equipment using appropriate cabling and port selection.

Part 4: Verify Connections
Accessed network tools and configurations to test end-to-end connectivity and ensure all links were functioning correctly.

Part 5: Examine the Physical Topology
Navigated through the physical layout of the network to understand device relationships, spatial organization, and overall structure.

Key Learnings

Basic navigation and interaction within a network simulator

Identification of common networking devices and their roles

Physical and logical connection of network components using correct cabling types

Network verification techniques to ensure reliable device connectivity

Improved familiarity with zooming, inspecting, and exploring physical network layouts
