Assessment Overview

This activity involved exploring and configuring a simulated network environment, focusing on basic networking tools, device identification, and expanding hardware capabilities to achieve connectivity.

Parts Completed

Part 1: Identify Physical Characteristics of Internetworking Devices
Explored the physical chassis and interfaces of various network hardware to identify power switches, slots, and fixed port layouts.

Part 2: Select Correct Modules for Connectivity
Evaluated network requirements to choose, install, and power on the appropriate hardware expansion modules required for specific media connections.

Part 3: Connect Devices
Practiced connecting internetworking devices and end hosts together using the correct cable types and specific interface designations.

Part 4: Check Connectivity
Accessed network interface tools and diagnostic utilities to test links, verify interface statuses, and ensure successful data transmission.

Key Learnings

Basic navigation and interaction within a network simulator

Identification of common networking devices and their physical attributes

Selection and installation of modular network hardware components

Physical and logical connection of network components using proper media

Network verification techniques to ensure reliable device connectivity
