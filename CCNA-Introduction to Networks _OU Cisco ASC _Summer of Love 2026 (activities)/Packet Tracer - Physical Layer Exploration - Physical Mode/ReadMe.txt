

Assessment Overview

This activity involved exploring and configuring a simulated network environment, focusing on basic networking tools, device identification, and analyzing local IP addressing and routing paths.

Parts Completed

Part 1: Examine Local IP Addressing Information
Explored the network interface of local end devices to locate, verify, and document their IP addresses, subnet masks, and default gateways.

Part 2: Trace the Path Between Source and Destination
Utilized network diagnostic tools to track the exact hops and route a packet takes as it travels from a source device across the network to its destination.

Key Learnings

Basic navigation and interaction within a network simulator

Identification of common networking devices and their roles

Verification and analysis of local IP configuration settings

Understanding network path selection and packet routing using tracing tools

Improved familiarity with zooming, inspecting, and exploring network layouts
