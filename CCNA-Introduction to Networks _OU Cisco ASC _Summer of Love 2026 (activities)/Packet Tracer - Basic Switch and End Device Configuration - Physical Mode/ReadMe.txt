Assessment Overview
This activity involved building a simple network topology in Packet Tracer Physical Mode (PTPM) by connecting hosts and switches, configuring fundamental device parameters via the command-line interface (CLI), implementing management IP addresses, and verifying complete network communication.

Parts Completed
Part 1: Set Up the Network Topology
Assembled a physical layout consisting of two network hosts and two switches, establishing the underlying connections required to build a functioning local area network.

Part 2: Configure PC Hosts
Applied specific IP addressing parameters to the computer hosts to provision them with network identities and prepare them for data communication.

Part 3: Configure and Verify Basic Switch Settings
Accessed the device CLI to initialize basic device parameters—including hostnames, local passwords, and login banners—while utilizing verification commands to review interface statuses and saving configurations using the copy command.

Key Learnings
Physical Device Initialization: Building a network from scratch using hosts and switches within a physical simulation environment.

Essential Device Hardening: Setting up core administrative configurations including custom hostnames, local access passwords, and legal login banners.

System Monitoring and Verification: Utilizing IOS show commands to audit the running configuration, check the operating system version, and inspect interface states.

Configuration Management: Saving active system parameters using the copy command to ensure configurations persist across device reboots.

Connectivity Testing: Deploying the ping diagnostic utility to test path reachability and confirm reliable end-to-end communication across the network.
