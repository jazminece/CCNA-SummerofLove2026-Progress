Assessment Overview
This activity focused on verifying network interface assignments and device connectivity, ensuring configured settings were active, and learning how to check the status of intermediary devices using the command-line interface (CLI).

Parts Completed
Part 1: Review PC Network Configurations
Utilized terminal utilities on end devices to display and confirm that local network settings were properly received and assigned.

Part 2: Verify Intermediary Device Interfaces
Accessed the switch CLI to run verification commands designed to quickly audit the condition, IP assignments, and operational status of all device interfaces.

Key Learnings
Contrast between verifying host network configurations and verifying intermediary infrastructure devices

Application of the show ip interface brief command to inspect port condition and IP addressing status

Importance of post-configuration testing to guarantee active network connectivity and functionality
