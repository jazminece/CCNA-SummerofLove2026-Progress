Assessment Overview
This activity involved exploring and configuring basic switch settings in a network environment, focusing on device initialization, security implementation, and configuration management.

Parts Completed
Part 1: Verify the Default Switch Configuration
Examined the initial state of the switch, checking default settings, interface statuses, and existing configurations before making modifications.

Part 2: Configure a Basic Switch Configuration
Accessed the command-line interface (CLI) to establish fundamental switch settings, including assigning device management details and basic security features.

Part 3: Configure a MOTD Banner
Created a Message of the Day (MOTD) banner to display legal notifications and unauthorized access warnings to users attempting to log into the device.

Part 4: Save Configuration Files to NVRAM
Committed the active running configuration to the non-volatile random-access memory (NVRAM) to ensure all settings persist after a device reboot or power cycle.

Part 5: Configure S2
Applied the established configuration steps, security settings, and management principles to the second switch (S2) within the network topology.

Key Learnings
Verification of out-of-the-box default device settings and states

Implementation of basic switch configurations and security management via CLI

Creation and deployment of legal MOTD banners for administrative compliance

Management of device memory by saving running configurations to permanent NVRAM

Replication of configuration procedures across multiple network switches
