Assessment Overview
This activity focused on testing end-to-end network connectivity, learning how to verify communication channels between multiple devices, and practicing basic troubleshooting techniques within a simulated network topology.

Parts Completed
Part 1: Test Connectivity to Network Infrastructure
Utilized network diagnostic tools from an end device to confirm successful communication with intermediary devices like switches.

Part 2: Verify Host-to-Host Communication
Executed testing procedures between individual computer hosts to ensure complete data transmission across the network path.

Key Learnings
Application of the ping command to check reachability to local network devices or internet websites

Analysis of ping results to determine the health and latency of end-to-end communication channels

Integration of systematic verification steps into the post-configuration workflow to ensure reliable deployment
