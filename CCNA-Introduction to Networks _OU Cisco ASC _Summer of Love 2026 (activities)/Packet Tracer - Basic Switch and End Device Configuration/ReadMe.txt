Assessment Overview

This activity focused on building a foundational network topology by initializing device naming conventions, implementing essential administrative security controls, assigning IP addressing across network hosts and infrastructure, and verifying complete end-to-end connectivity via the command-line interface (CLI).

Parts Completed

Part 1: Configure Switch Hostnames and IP Addressing

Accessed the CLI on multiple Cisco IOS switches to assign unique network identifiers and configure management IP addresses for remote access.

Part 2: Implement Device Access Security

Utilized Cisco IOS security commands to limit and restrict access to privileged device modes, protecting configuration settings from unauthorized users.

Part 3: Configure Host IP Parameters

Configured network interface cards (NICs) on computer end devices with correct IP addresses and subnet masks to enable local network communication.

Part 4: Save Device Configurations to NVRAM

Committed all active running configurations to non-volatile random-access memory (NVRAM) to guarantee device parameters remain intact after a restart.

Part 5: Verify End-to-End Connectivity

Executed diagnostic commands between the configured host PCs to test communication pathways and confirm a successful operational state.

Key Learnings

Command-line execution for establishing unique host identities and management addressing on Cisco IOS switches

Application of password criteria and access controls to secure device infrastructure lines

Administrative file management practices to save operational configurations into permanent storage

Standard IP assignment workflows for integrating end hosts into a shared subnet topology

Analysis of end-to-end diagnostic tools to troubleshoot and ensure total path reachability
